# Mensetsu — 研修医マッチング面接 準備キット

先輩の面接回答集をベースに、**誰でも自分だけの回答集を作れる**ようにまとめたキットです。
友達に共有すれば、同じ手順で準備できます。

## 中身

| ファイル | 用途 |
|---|---|
| **面接準備プロンプト.md** | どのAI（ChatGPT / Gemini / Claude）に貼っても、1問ずつ聞いて回答を仕上げてくれる指示文。**これが本体。** |
| **質問バンク.md** | 先輩の約200問を整理した質問リスト（チェックリスト付き） |
| **index.html** | 上記をまとめた共有用Webページ（URLで友達に送れる） |
| **面接回答集_テンプレート.xlsx** | 記入用Excelテンプレート（共通・医療社会系・病院×5シート／3列） |
| **面接回答集_テンプレート.docx** | 記入用Wordテンプレート（セクション見出し＋3列の表） |

## 使い方（友達に渡すとき）

**方法1：URLを送る（一番かんたん）**
共有Webページ（GitHub Pages）👉 https://hellowinners861.github.io/Mensetsu/
リンクを開いて「コピー」→ 好きなAIに貼るだけ。
※ このブランチへのプッシュで GitHub Actions（`.github/workflows/deploy-pages.yml`）が自動デプロイします。

**方法2：ファイルを渡す**
`面接準備プロンプト.md` の指示文をコピーして、AIの最初のメッセージに貼り付け。
先輩のExcelがあれば一緒に添付するとより正確になります。

## 進め方
1. AIがまず「土台情報（受ける病院・打ち込んだこと・志望科など）」を聞く
2. そのあと面接質問を**1問ずつ**出題
3. キーワード程度で答えると、AIが「質問／回答／深掘り対策」の3列で仕上げてくれる
4. 共通質問 → 医療社会系 → 病院別、の順で回答集が完成
5. 最後にAIへ「まとめて」と送ると、Excelへ貼れるTSV／Word用の表で書き出してくれる
   （対応AIなら `.xlsx`/`.docx` を直接生成。配布サイトの空テンプレートに貼るだけでも完成）
